ScribbleDB

Describe a database in plain words. An agentic pipeline writes the schema and rules, plans and codes a generator, checks every rule, audits the data for realism, revises the rules and hands you a verified package. Everything runs in your browser with your own model key.

Model

The key goes from this page straight to your provider; there is no server of ours. If a setting is not supported by the model (for example reasoning effort), the pipeline drops it and says so in the timeline.
